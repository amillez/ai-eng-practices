# Steal from pstack

What we adopt from poteto's pstack vs what we only link. pstack skills are plain `SKILL.md` files, so the ideas port to Claude Code / Codex without installing the Cursor plugin (Cursor plugin trial is **not** required; Cursor coding is abandoned). Do **not** wholesale-install pstack on `agent-m1`. poteto-mode itself is adopted as the `amillez-mode` skill (below).

## Adopt into our stack (now / next)

- **poteto-mode → `amillez-mode`.** **Adopted (2026-09-27)** into `amillez/agent-skills` as [`skills/amillez-mode`](https://github.com/amillez/agent-skills/tree/main/skills/amillez-mode), pinned to pstack 0.15.5 (`ecc249f`). It carries the 23 principles, unslop, technical-writing, tdd, and the ported playbooks, remapped to our lanes, Argent and `verify-*` proof, and never-merge. Required for every coding agent (single or Orca worker) per [agent use policy](../policies/agent-use-policy.md#1-coding-host-routing). The worker brief template and retry by failure mode from pstack `orchestrate.md` went into `orchestrate-agents`. Per-file verdicts: [`UPSTREAM.md`](https://github.com/amillez/agent-skills/blob/main/skills/amillez-mode/UPSTREAM.md). Pointer: [amillez-mode](amillez-mode.md).
- **Babysit until merged.** Already in [agent-dispatch-lifecycle.md](agent-dispatch-lifecycle.md#babysit-until-merged). Align eng-bot watches with pstack's babysit playbook: drive the PR through conflicts, review, and CI; do not drop it when the agent goes idle. Our rule: the bot owns the workstream until `merged` | `discarded`; arm a finite session-settle ping; prefer a GitHub PR listener over polling. **Next (from pstack 0.15.3 autopilot):** verification *rounds* that re-run when the code-ready head changes, and a small `children.tsv` (or equivalent) so the owner tracks subagents and only posts status when a tracked item changed. Port the idea into eng-bot babysit notes, not the Cursor autopilot scripts. The coding agent's side of a babysit is ported as amillez-mode `playbooks/babysit.md`.
- **Prove it works** — maps to [agent-proof-feedback-loop.md](agent-proof-feedback-loop.md). Real artifact evidence (sims, screens, logs), not "it compiles." Luna Max for visual verify; media on the `media` branch.
- **Blast radius.** **Adopted (2026-09-27)** as amillez-mode [`playbooks/blast-radius.md`](https://github.com/amillez/agent-skills/blob/main/skills/amillez-mode/playbooks/blast-radius.md). For a small diff you do not fully trust, find the *one fact* the change is safe because of and prove it by running real code, not a convincing writeup. Linked from the Investigation router entry, the PR body's Blast Radius section, and review triage.
- **Show me your work.** **Adopted (2026-09-27)** as amillez-mode [`references/show-me-your-work.md`](https://github.com/amillez/agent-skills/blob/main/skills/amillez-mode/references/show-me-your-work.md), with its TSV template and `scripts/decision-log.sh`. Hillclimb and Autonomous run no longer carry an inline `decision.tsv` spec. They point at this reference, and a trigger in amillez-mode's Non-negotiables requires a decision trail for long, autonomous, or later-reviewed work.
- **Figure it out.** **Adopted (2026-09-27)** as amillez-mode [`playbooks/figure-it-out.md`](https://github.com/amillez/agent-skills/blob/main/skills/amillez-mode/playbooks/figure-it-out.md). The single-agent path for long, cross-cutting, or later-reviewed work. The one-line rule is in the [size gate](../policies/agent-use-policy.md#1-coding-host-routing). Needs parallel workers → Orca. One agent owns the whole loop → Figure it out.
- **Recall.** **Adopted (2026-09-27)**, folded into amillez-mode [`playbooks/session-pickup.md`](https://github.com/amillez/agent-skills/blob/main/skills/amillez-mode/playbooks/session-pickup.md) as a shared-record sweep (git history, reverts, `gh` issues and PRs, connected trackers, committed decision trails). No separate skill.
- **TypeScript best practices.** **Adopted (2026-09-27)** as the separate core skill [`typescript-best-practices`](https://github.com/amillez/agent-skills/blob/main/skills/typescript-best-practices/SKILL.md), on the [skills allowlist](agent-proof-feedback-loop.md#skills-allowlist). Grounds amillez-mode's type-system and boundary principles in TypeScript. Defers React Native library usage to `react-native-best-practices`.
- **Reflect.** **Adopted (2026-09-27)** as amillez-mode [`playbooks/reflect.md`](https://github.com/amillez/agent-skills/blob/main/skills/amillez-mode/playbooks/reflect.md), the one fan-out skill ported. Explicit invoke only. Three reviewers on different lanes read a finished Claude Code or Codex session log, a synthesizer on Opus 5.5 xHigh filters the learnings, and the result is one small PR for review (never merged) or a hand-off to the weekly garden. Installed skills are never edited in place.
- **Project verification skill pattern** — **Adopted (now)** into `amillez/agent-skills` `first-party/` as `create-verification-skill` + `maintain-verification-skill`, with an **amillez-mode overlay** (not a wholesale pstack install):
  - Keep: interview repo → generate `verify-<app>` → feature map shape → prove before handoff → maintain-loop rigor. Evidence dry-run nuance: some dry-runs still touch network/browser — observe what they skip, do not trust the name.
  - Overlay: default output under project-local `.claude/skills/verify-<app>/` and/or `.codex/skills/verify-<app>/` on agent-m1 only (never `.cursor/skills/`); generate/prove on agent-m1; Argent for Expo/RN; screenshots/videos → `media` branch + Luna Max (Codex) verify ([agent-proof-feedback-loop](agent-proof-feedback-loop.md), [agent-use-policy](../policies/agent-use-policy.md), [amillez-mode](amillez-mode.md)).
  - **Bot designer (Stella):** day-one wiring for coding bots on driveable apps — point at create + maintain; skip for pure library/docs/non-coding bots. Host stays agent-m1-first in the bot brief.
  - Next use: generate for Expo/RN apps (Favvy, asnt) via Argent Drive/Evidence. Do not require the Cursor plugin.

Points at [agent-use-policy](../policies/agent-use-policy.md) chooser (GPT 6 Luna Max / Opus 5.5 High / GPT 6 Sol fallback over 70% Claude Code usage / Fable 5.1). Our chooser stays amillez policy — do not copy pstack's Cursor rule file; just keep lanes current (see open lane PRs).
- **Worktree cleanup.** Already required in dispatch teardown (plus sim/Metro teardown). **Adopted** as amillez-mode `playbooks/worktree-cleanup.md` with a read-only `scripts/worktree-audit.sh`.

## Steal selectively later

- **Shipping.** Dropped for v1 in amillez-mode. Agents never merge; only Agustín's say-so merges. The idea worth keeping is independent verification (a different agent verifies than the one that wrote).
- **Fan-out skills (`how`, `why`, `architect`, `arena`, `swarm`, `interrogate`).** Dropped for v1 in amillez-mode. `reflect` is the exception, adopted above. Use read-only recon and a plan ([agent use policy §5](../policies/agent-use-policy.md#5-plan-before-build-non-trivial-work)), `grill-me` for contested plans, and a same-prompt second opinion on a different lane. Structured multi-agent fan-out is **Orca** on `agent-m1` with an Opus 5.5 xhigh coordinator ([big-work-orchestration.md](big-work-orchestration.md)). Revisit only if those fall short.
- **Automate-me / personal `*-mode`** — optional later: an Agustín-mode router on top of agent-use-policy. Not blocking.
- **Post-merge "rollouts" pattern (idea only)** — Cursor's Rollouts bot (Sep 2026) watches PR→deploy with a monitoring plan vs telemetry. We are not on Cursor coding; if we ever want the *pattern*, sketch a Grok Bot + PagerDuty/Sentry listener after merge — do not install Cursor Rollouts.
